# Bubble Aim

Free single-file HTML5 bubble shooter. Aim with mouse or touch, bounce shots
off the walls, match 3+ bubbles of the same color to pop them, and drop
detached clusters for bonus points. Clear the board to advance — colors
increase and the ceiling pushes down faster every level.

**Play:** https://shuangyueliao.github.io/bubble-aim/

- Mouse / touch / arrow keys, aim preview with wall-bounce prediction
- Procedural graphics & WebAudio sounds, one HTML file, zero dependencies
- Best score & best level saved locally
